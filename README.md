# نظام الطلبات الإدارية - قسم الكهرباء والإلكترونيات (نسخة عرض)

نسخة واجهة فقط (HTML/CSS/JS) تشتغل على GitHub Pages بدون سيرفر.
كل البيانات تنحفظ في متصفح كل مستخدم (localStorage)، يعني هي **للعرض والتجربة فقط**:
الطلب اللي يرسله موظف من جهازه ما يوصل لرئيس القسم على جهاز ثاني.

## حسابات تجريبية (كلمة المرور 123456)
| المستخدم | الصلاحية | الاسم |
|---|---|---|
| admin | مدير النظام | عبدالرزاق الهاجري |
| head | رئيس القسم | مقدم مهندس بحري / فهد عبدالرحمن الفيلكاوي |
| officer | ضابط قسم | (اسم تجريبي) |
| pro | مسئول المهنيين | (اسم تجريبي) |
| clerk, clerk2 | إداري | (أسماء تجريبية) |
| emp, emp2, pemp | موظف / مهني | (أسماء تجريبية) |

## سير الطلبات
- **إجازة مهنيين / إذن مغادرة (مهنيين)**: مسئول المهنيين يوافق أولاً ← رئيس القسم ← الإداري للتنفيذ.
- باقي الطلبات: رئيس القسم أو ضابط القسم ← الإداري.
- الاستئذان 3 ساعات بالضبط، وحد 4 بالشهر.
- إذا انرسل الاستئذان أو الإجازة أو العارضة أو الطبية بعد أكثر من يومين من تاريخه، يوصل عادي بس يطلع عليه تنبيه «احتمال رفض بسبب التأخير في الإرسال».
- كل موافقة تطلع بختم فيه اسم الشخص ورتبته ومسماه.
- الإحصائية يعتمدها الإداري بزر «اعتماد الإحصائية».
