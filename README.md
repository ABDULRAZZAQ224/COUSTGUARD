# نظام الطلبات الإدارية - قسم الكهرباء والإلكترونيات (نسخة عرض)

نسخة واجهة فقط (HTML/CSS/JS) تعمل على GitHub Pages بدون خادم، **بلغتين: عربي و English** (زر تبديل اللغة في الأعلى).
كل البيانات تُحفظ في متصفح كل مستخدم (localStorage)، أي أنها **للعرض والتجربة فقط**:
الطلب الذي يرسله موظف من جهازه لا يصل إلى جهاز آخر.

## سير الطلبات
- **الاعتماد من الإداري** لكل الطلبات المقدّمة في موعدها، ثم يقوم الإداري بالتنفيذ («تم عمل اللازم» أو «يرجى المتابعة»).
- **إجازة مهنيين / إذن مغادرة (مهنيين)**: يعتمدها **مسؤول المهنيين**، ثم التنفيذ عند الإداري.
- **الطلب المتأخر** (استئذان أو إجازة أو عارضة أو طبية أو إجازة مهنيين قُدِّم بعد مضيّ أكثر من يومين على تاريخه): يصل عاديًا إلى الإداري (أو مسؤول المهنيين) مع تنبيه باحتمال الرفض، وختم اعتماده «اعتماد (طلب متأخر)».
- **رئيس القسم وضابط القسم**: للاطلاع والمتابعة فقط (صفحة «متابعة الطلبات» والإحصائيات)، بدون اعتماد أو رفض.
- **مدير النظام** يملك كل الصلاحيات، وإذا وقّع في مرحلة مسؤول المهنيين يظهر ختمه «اعتماد عن مسؤول المهنيين».
- **طلب المقابلة**: يجب اختيار المسؤول (رئيس القسم، ضابط القسم، مدير الإدارة، المدير العام) وكتابة سبب المقابلة.
- **الإجازات**: يظهر تنبيه «يجب على الموظف عند تقديم طلب الإجازة الحضور إلى القسم لاعتمادها، كما يجب عليه الحضور إلى القسم ومباشرة العمل فور انتهاء الإجازة».
- الاستئذان 3 ساعات بالضبط، وبحد أقصى 4 في الشهر.
- لكل طلب **رقم صادر** (مثل 2026/0012)، وفي **سجل العمليات** يمكن البحث برقم الصادر والضغط عليه لفتح الكتاب وسجله.
- كل اعتماد يظهر بختم فيه اسم الشخص ورتبته ومسماه، وكل شيء قابل للطباعة.
- **زام الإداري** (مدير النظام): إضافة الأشخاص المداومين وحذفهم، وتحديد آلية عمل كل شخص (أيام ثابتة من الأسبوع أو مناوبة دورية: أيام عمل ثم أيام راحة)، والنظام يحسب تلقائيًا من المداوم اليوم، ويعرض الأيام الـ14 القادمة، ويضع المداوم أولًا في تذكير الواتساب.
- **الإحصائيات**: اختيار الفترة وموظف معيّن (أو جميع الموظفين). زر «اعتماد وطباعة هذه الإحصائية» (للإداري أو مسؤول المهنيين أو مدير النظام) يضع الختم لهذه الطباعة فقط، ثم تعود الإحصائية طبيعية بدون اعتماد.
